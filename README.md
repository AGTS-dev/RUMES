# RUMES Messenger

Современный мессенджер с полной функциональностью: чаты, контакты, звонки, сохранённые сообщения и кастомизация тем.

## 🎨 Темы оформления

### 🌙 Тёмная тема (по умолчанию)
- Чёрный фон (#000000)
- Минималистичный дизайн
- **Кастомный акцентный цвет** — выберите любой цвет для акцентов

### ☀️ Светлая тема
- Белый фон (#ffffff)
- Классический светлый интерфейс
- **Кастомный акцентный цвет** — настройте под свой вкус

### 🌈 Радужная тема
- Яркие градиенты и неоновые цвета
- **Полная кастомизация** — настройте все 6 цветов:
  - Основной фон
  - Вторичный фон
  - Третичный фон
  - Акцентный цвет
  - Основной текст
  - Вторичный текст

## ✨ Возможности

### 💬 Чаты
- Список чатов с фильтрами (Все, Личные, Группы, Каналы, Боты)
- 🔍 Поиск по чатам
- 📤 Отправка сообщений (Enter или кнопка)
- 🤖 Автоответы с индикатором "печатает..."
- ✓✓ Статусы сообщений (отправлено, доставлено, прочитано)
- 🟢 Онлайн-статусы пользователей

### 👥 Контакты
- Список всех контактов с поиском
- Информация о контакте: имя, телефон, username, био
- Статус онлайн/офлайн с временем последнего визита
- Быстрые действия: аудиозвонок, видеозвонок
- **Готово к интеграции с бэкендом** (см. API_SPEC.md)

### 📞 Звонки
- История всех звонков (входящие, исходящие, пропущенные)
- Фильтры по типу звонка
- Информация о звонке: контакт, тип (аудио/видео), длительность, время
- Цветовая индикация пропущенных звонков
- Кнопка быстрого перезвона
- **Готово к интеграции с бэкендом** (см. API_SPEC.md)

### ⭐ Сохранённые сообщения
- Список всех сохранённых сообщений
- Поиск по сохранённым сообщениям
- Типы сообщений: текст, ссылки, заметки
- Информация об источнике (из какого чата сохранено)
- Действия: копировать, удалить
- **Готово к интеграции с бэкендом** (см. API_SPEC.md)

### ⚙️ Настройки
- Переключение между тремя темами
- Кастомный акцентный цвет для Dark/Light тем
- Полная кастомизация радужной темы (6 цветов)
- Color picker + 10 пресетов
- Сохранение настроек в localStorage

## 🎯 Использование

### Переключение тем
1. Нажмите на иконку ⚙️ в левой панели
2. Выберите нужную тему:
   - 🌙 Тёмная
   - ☀️ Светлая
   - 🌈 Радужная

### Настройка акцентного цвета (Dark/Light)
1. Выберите тему Dark или Light
2. В разделе "Акцентный цвет" используйте color picker
3. Или выберите из 10 предустановленных цветов
4. Цвет применится мгновенно

### Кастомизация радужной темы
1. Выберите тему Rainbow
2. В разделе "Кастомизация радужной темы" настройте:
   - Основной фон
   - Вторичный фон
   - Третичный фон
   - Акцентный цвет
   - Основной текст
   - Вторичный текст
3. Используйте кнопку "Сбросить" для возврата к стандартным цветам

### Контакты
1. Нажмите на иконку 👥 в левой панели
2. Просмотрите список контактов
3. Используйте поиск для быстрого нахождения
4. Нажмите на кнопку звонка для быстрого действия

### Звонки
1. Нажмите на иконку 📞 в левой панели
2. Просмотрите историю звонков
3. Используйте фильтры для отображения нужных звонков
4. Нажмите на кнопку перезвона для быстрого действия

### Сохранённые сообщения
1. Нажмите на иконку ⭐ в левой панели
2. Просмотрите список сохранённых сообщений
3. Используйте поиск для быстрого нахождения
4. Копируйте или удаляйте сообщения

## 💾 Хранение настроек

Все настройки сохраняются в localStorage:
- `rumes-theme` — выбранная тема
- `rumes-custom-accent` — кастомный акцентный цвет
- `rumes-rainbow-colors` — кастомные цвета радужной темы

## 📖 API для бэкенда

Полная спецификация API находится в файле **API_SPEC.md**

### Основные endpoints:
- `GET/POST/PUT/DELETE /api/contacts` — управление контактами
- `GET/POST/DELETE /api/calls` — история звонков
- `GET/POST/PUT/DELETE /api/saved-messages` — сохранённые сообщения

### WebSocket события:
- `contact:online` / `contact:offline` — статусы контактов
- `call:incoming` / `call:ended` / `call:missed` — звонки
- `saved-message:created` / `saved-message:deleted` — сохранённые сообщения

## 🎨 Особенности дизайна

- **Минимализм** — чистый интерфейс без лишних элементов
- **Три темы** — переключение одним кликом

- **Адаптивность** — работает на всех устройствах
- **Доступность** — контрастные цвета, читаемые шрифты
