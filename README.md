# Telegram Web Clone

Высокоточная визуальная копия Telegram Desktop Web (web.telegram.org/k) на React + TypeScript + Tailwind CSS.

## 🎨 Особенности

- **Трёхколоночная структура** как в оригинале:
  - Левая панель (70px) с иконками навигации
  - Средняя панель со списком чатов
  - Правая панель с окном переписки

- **Точные цвета Telegram**:
  - Фон: `#0e1621`
  - Панели: `#17212b`
  - Активный чат: `#2b5278`
  - Входящие сообщения: `#182533`
  - Исходящие сообщения: `#2b5278`

- **Шрифт Roboto** с правильными размерами
- **12 чатов** с реалистичными русскими именами и сообщениями
- **Фильтры**: Все | Личные | Группы | Каналы | Боты
- **Пузыри сообщений** с хвостиками, временем и галочками прочтения
- **Адаптивный дизайн**: мобильная версия с переключением между списком и чатом
- **Hover-эффекты** и плавные анимации (150ms transitions)
- **Индикатор набора текста** с анимированными точками
- **Автоответы** от собеседников

## 🚀 Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build

# Проверка типов
npm run typecheck
```

## 📁 Структура проекта

```
src/
├── components/
│   ├── LeftSidebar.tsx       # Левая панель с иконками (70px)
│   ├── ChatList.tsx          # Средняя панель со списком чатов
│   ├── ChatWindow.tsx        # Правая панель с окном чата
│   ├── ChatHeader.tsx        # Хедер чата с аватаром и статусом
│   ├── MessageBubble.tsx     # Пузырь сообщения
│   └── MessageInput.tsx      # Поле ввода сообщения
├── data/
│   └── mockData.ts           # Моковые данные (12 чатов)
├── App.tsx                   # Главный компонент
├── index.css                 # Стили с точными цветами Telegram
└── main.tsx                  # Точка входа

```

## 🎨 Стили

Все стили соответствуют оригинальному Telegram Web:
- Тёмная тема по умолчанию
- Шрифт Roboto
- Hover-эффекты на всех интерактивных элементах
- Курсор pointer
- Плавные transition 150ms
- Кастомные скроллбары
- Анимации появления сообщений

## 📝 Примечания

Проект использует:
- **React 18** с хуками
- **TypeScript** для типизации
- **Tailwind CSS** для стилей
- **Lucide React** для иконок
- **Vite** для сборки

Моковые данные включают 12 чатов с разными типами:
- Личные чаты (7)
- Группы (2)
- Каналы (1)
- Боты (1)
- Избранное (1)

## 🔧 Кастомизация

Для изменения цветовой схемы отредактируйте `src/index.css`:
```css
.bg-telegram-bg { background: #0e1621; }
.bg-telegram-panel { background: #17212b; }
.bg-telegram-active { background: #2b5278; }
/* ... */
```
