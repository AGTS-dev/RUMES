# RUMES Messenger

Современный мессенджер с тремя темами оформления: тёмная, светлая и радужная.

## 🎨 Темы оформления

### 🌙 Тёмная тема (по умолчанию)
- Чёрный фон (#000000)
- Минималистичный дизайн
- Идеально для ночного использования

### ☀️ Светлая тема
- Белый фон (#ffffff)
- Классический светлый интерфейс
- Комфортна для дневного использования

### 🌈 Радужная тема
- Яркие градиенты и неоновые цвета
- Фиолетовый, розовый, золотой, зелёный
- Для тех, кто любит выделяться

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build
```

Откройте http://localhost:5173

## 🎯 Использование

### Переключение тем
1. Нажмите на иконку ⚙️ в левой панели
2. Выберите нужную тему:
   - 🌙 Тёмная
   - ☀️ Светлая
   - 🌈 Радужная
3. Тема сохраняется в localStorage

### Отправка сообщений
- Введите текст в поле ввода
- Нажмите **Enter** для отправки
- Или нажмите кнопку 📤

### Поиск чатов
- Используйте поле поиска в верхней части списка чатов
- Фильтры: Все, Личные, Группы, Каналы, Боты

## 📊 Моковые данные

12 чатов включают:
- 7 личных чатов
- 2 группы
- 1 канал
- 1 бот
- 1 избранное

Каждый чат содержит историю из 3-6 сообщений.
