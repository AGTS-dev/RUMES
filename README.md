# RUMES Messenger

Современный мессенджер с расширенными настройками, множеством тем и полной кастомизацией.

## 🎨 Темы оформления

### 🌙 Тёмная тема (по умолчанию)
- Чёрный фон (#000000)
- Минималистичный дизайн
- **Кастомный акцентный цвет** — выберите любой цвет для акцентов

### ☀️ Светлая тема
- Белый фон (#ffffff)
- Классический светлый интерфейс
- **Кастомный акцентный цвет** — настройте под свой вкус

### 🎨 Своя тема
- Полная кастомизация 6 цветов
- Настройте каждый элемент интерфейса
- Сохранение в localStorage

### 💾 Windows 98
- Олдскул интерфейс в стиле Windows 98
- 3D-кнопки с outset/inset borders
- Teal рабочий стол (#008080)
- Квадратные углы везде
- Шрифт MS Sans Serif

### 🇷🇺 Россия
- Тематический дизайн с цветами российского флага
- Белый, синий (#0039A6), красный (#D52B1E)
- Градиентные акценты
- Тематические обои: флаг, Кремль, берёзы, зима

## 🖼️ Обои чата

### Стандартные обои
- По умолчанию
- 5 градиентов (синий, закат, океан, лес, ночь)
- 2 паттерна (точки, сетка)
- 2 сплошных (тёмный, серый)

### Тематические обои
- **Флаг России** — триколор
- **Кремль** — градиент красный-синий-белый
- **Берёзы** — бежево-зелёный
- **Зима** — светло-голубой

## 🎯 Использование

### Переключение тем
1. Нажмите на иконку ⚙️ в левой панели
2. Перейдите на вкладку "Оформление"
3. Выберите нужную тему:
   - 🌙 Тёмная
   - ☀️ Светлая
   - 🎨 Своя
   - 💾 Windows 98
   - 🇷🇺 Россия

### Настройка акцентного цвета (Dark/Light)
1. Выберите тему Dark или Light
2. На вкладке "Оформление" используйте color picker
3. Или выберите из 10 предустановленных цветов
4. Цвет применится мгновенно

### Кастомизация темы "Своя"
1. Выберите тему "Своя"
2. На вкладке "Оформление" настройте 6 цветов
3. Используйте кнопку "Сбросить" для возврата к стандартным цветам

### Выбор обоев
1. Перейдите на вкладку "Обои"
2. Выберите один из 14 вариантов
3. Обои применятся мгновенно
4. Выбор сохраняется в localStorage

### Аудио/видеозвонки
1. Откройте чат
2. Нажмите на иконку телефона (аудио) или видеокамеры
3. Дождитесь "подключения" (3 секунды)
4. Используйте кнопки управления
5. Завершите звонок красной кнопкой

### Поиск в чате
1. Откройте чат
2. Нажмите на иконку поиска или выберите "Поиск в чате" из меню
3. Введите текст для поиска
4. Кликните по результату для перехода к сообщению

## 💾 Хранение настроек

Все настройки сохраняются в localStorage:
- `rumes-theme` — выбранная тема
- `rumes-custom-accent` — кастомный акцентный цвет
- `rumes-custom-colors` — кастомные цвета темы "Своя"
- `rumes-wallpaper` — выбранные обои

## 🎨 Цветовые схемы

### Тёмная тема
```css
--bg-primary: #000000
--bg-secondary: #0a0a0a
--text-primary: #ffffff
--accent: [кастомный]
```

### Светлая тема
```css
--bg-primary: #ffffff
--bg-secondary: #f5f5f5
--text-primary: #000000
--accent: [кастомный]
```

### Россия
```css
--bg-primary: #ffffff
--bg-secondary: #f0f4f8
--accent: #D52B1E (красный)
--bg-active: #0039A6 (синий)
```

### Windows 98
```css
--bg-primary: #008080 (teal)
--bg-secondary: #c0c0c0 (серый)
--accent: #000080 (navy)
```
