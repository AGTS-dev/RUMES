# RUMES Messenger

Современный мессенджер с расширенными настройками, множеством тем и полной кастомизацией.

## 🎨 Темы оформления

### 🌙 Тёмная тема (по умолчанию)
- Чёрный фон (#000000)
- Минималистичный дизайн
- **Кастомный акцентный цвет** — выберите любой цвет для акцентов

### ☀️ Светлая тема
- Белый фон (#ffffff)
- Классический светлый интерфейс
- **Кастомный акцентный цвет** — настройте под свой вкус

### 🎨 Своя тема
- Полная кастомизация 6 цветов
- Настройте каждый элемент интерфейса
- Сохранение в localStorage

### 💾 Windows 98
- Олдскул интерфейс в стиле Windows 98
- 3D-кнопки с outset/inset borders
- Teal рабочий стол (#008080)
- Квадратные углы везде
- Шрифт MS Sans Serif

### 👑 Россия
- Тематический русский дизайн
- Золотые и красные акценты (#c41e3a, #ffd700)
- Русские узоры на фоне
- Кокошник в логотипе 👑
- Декоративные золотые рамки
- Тематические обои: Кокошник, Узоры, Берёзовая роща, Русская зима

## 📏 Resizable Chat List 🆕

Для ПК версии доступна функция изменения ширины списка чатов:

- **Минимальная ширина**: 70px (только аватарки)
- **Максимальная ширина**: 600px
- **По умолчанию**: 360px
- **Как использовать**: наведите курсор на правую границу списка чатов и перетаскивайте

## 🎯 Использование

### Переключение тем
1. Нажмите на иконку ⚙️ в левой панели
2. Перейдите на вкладку "Оформление"
3. Выберите нужную тему:
   - 🌙 Тёмная
   - ☀️ Светлая
   - 🎨 Своя
   - 💾 Windows 98
   - 👑 Россия

### Создание папок
1. Откройте Настройки
2. Перейдите на вкладку "Папки"
3. Нажмите "Создать папку"
4. Введите название
5. Выберите иконку (20 вариантов)
6. Выберите цвет (10 вариантов)
7. Нажмите "Создать"

### Изменение ширины списка чатов
1. Наведите курсор на правую границу списка чатов
2. Курсор изменится на `col-resize`
3. Перетаскивайте влево/вправо
4. Ширина меняется от 70px до 600px

### Использование эмодзи
1. Откройте чат
2. Нажмите на иконку 😊
3. Выберите категорию
4. Кликните на нужный эмодзи
5. Эмодзи вставится в поле ввода

### Выбор обоев
1. Перейдите в Настройки → Обои
2. Выберите один из 14 вариантов
3. Обои применятся мгновенно

## 💾 Хранение настроек

Все настройки сохраняются в localStorage:
- `rumes-theme` — выбранная тема
- `rumes-custom-accent` — кастомный акцентный цвет
- `rumes-custom-colors` — кастомные цвета темы "Своя"
- `rumes-wallpaper` — выбранные обои
- `rumes-folders` — пользовательские папки

## 🎨 Цветовые схемы

### Тёмная тема
```css
--bg-primary: #000000
--bg-secondary: #0a0a0a
--text-primary: #ffffff
--accent: [кастомный]
```

### Светлая тема
```css
--bg-primary: #ffffff
--bg-secondary: #f5f5f5
--text-primary: #000000
--accent: [кастомный]
```

### Россия 👑
```css
--bg-primary: #fff8e7 (кремовый)
--bg-secondary: #fff3d4 (светло-жёлтый)
--accent: #c41e3a (красный)
--bg-active: #c41e3a (красный)
--border-color: #d4a574 (золотистый)
```

### Windows 98 💾
```css
--bg-primary: #008080 (teal)
--bg-secondary: #c0c0c0 (серый)
--accent: #000080 (navy)
```
