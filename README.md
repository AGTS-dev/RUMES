# RUMES Messenger

Современный мессенджер с тремя темами оформления и полной кастомизацией цветов.

## 🎨 Темы оформления

### 🌙 Тёмная тема (по умолчанию)
- Чёрный фон (#000000)
- Минималистичный дизайн
- **Кастомный акцентный цвет** — выберите любой цвет для акцентов

### ☀️ Светлая тема
- Белый фон (#ffffff)
- Классический светлый интерфейс
- **Кастомный акцентный цвет** — настройте под свой вкус

### 🌈 Радужная тема
- Яркие градиенты и неоновые цвета
- **Полная кастомизация** — настройте все 6 цветов:
  - Основной фон
  - Вторичный фон
  - Третичный фон
  - Акцентный цвет
  - Основной текст
  - Вторичный текст

## 🎨 Цветовая схема

### Тёмная тема (с кастомным акцентом)
```css
--bg-primary: #000000
--bg-secondary: #0a0a0a
--text-primary: #ffffff
--accent: [выбранный пользователем]
```

### Светлая тема (с кастомным акцентом)
```css
--bg-primary: #ffffff
--bg-secondary: #f5f5f5
--text-primary: #000000
--accent: [выбранный пользователем]
```

### Радужная тема (полная кастомизация)
```css
--bg-primary: [выбранный]
--bg-secondary: [выбранный]
--bg-tertiary: [выбранный]
--accent: [выбранный]
--text-primary: [выбранный]
--text-secondary: [выбранный]
```

## 🎯 Использование

### Переключение тем
1. Нажмите на иконку ⚙️ в левой панели
2. Выберите нужную тему:
   - 🌙 Тёмная
   - ☀️ Светлая
   - 🌈 Радужная

### Настройка акцентного цвета (Dark/Light)
1. Выберите тему Dark или Light
2. В разделе "Акцентный цвет" используйте color picker
3. Или выберите из 10 предустановленных цветов
4. Цвет применится мгновенно

### Кастомизация радужной темы
1. Выберите тему Rainbow
2. В разделе "Кастомизация радужной темы" настройте:
   - Основной фон
   - Вторичный фон
   - Третичный фон
   - Акцентный цвет
   - Основной текст
   - Вторичный текст
3. Используйте кнопку "Сбросить" для возврата к стандартным цветам

### Сохранение настроек
- Все настройки автоматически сохраняются в localStorage
- При следующем открытии приложения восстановятся ваши настройки

## 🎨 Особенности дизайна

- **Минимализм** — чистый интерфейс без лишних элементов
- **Три темы** — переключение одним кликом

- `rumes-rainbow-colors` — кастомные цвета радужной темы
