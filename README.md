  if (e.key === 'Enter' && !e.shiftKey) {

## 🎯 Функциональность

### Переключение вкладок
- Клик на иконку → `setActiveTab(tab)`
- Если `tab !== 'chats'` → показывается заглушка
- Если `tab === 'chats'` → показывается список чатов

### Выбор чата
- Клик на чат → `setActiveChatId(chatId)`
- Чат подсвечивается синим
- Правая панель показывает ChatWindow

### Отправка сообщений
- Ввод текста → `setText(text)`
- Enter или кнопка → `onSendMessage(text)`
- Автоответ через 2-4 секунды
- Индикатор "печатает..." через 500ms

### Кнопки действий
- Все кнопки имеют `onClick` обработчики
- Показывают `alert()` с сообщением
- Логируют в `console.log()`
