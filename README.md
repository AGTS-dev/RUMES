## 🎯 Использование

### Мобильная навигация
1. Нажмите на hamburger меню (три полоски) в левом верхнем углу
2. Выберите нужный раздел
3. Меню закроется автоматически
4. Для возврата нажмите кнопку "Назад" или hamburger снова

### Resizable Chat List
1. Наведите курсор на правую границу списка чатов
2. Перетаскивайте влево/вправо
3. При отпускании ширина "прилипнет" к ближайшему snap point:
   - 70px (compact mode — только аватарки)
   - 360px (стандартная ширина)
   - 600px (максимальная ширина)

### Тематические обои
1. Выберите тему "Россия" в настройках
2. Перейдите в Настройки → Обои
3. Выберите один из тематических обоев:
   - **Хохлома** — чёрный фон с золотыми узорами
   - **Гжель** — белый фон с синими узорами
   - **Кокошник** — красно-золотой градиент
   - **Берёзовая роща** — природа
   - **Русская зима** — зимний пейзаж

## 💾 Хранение настроек

Все настройки сохраняются в localStorage:
- `rumes-theme` — выбранная тема
- `rumes-custom-accent` — кастомный акцентный цвет
- `rumes-custom-colors` — кастомные цвета темы "Своя"
- `rumes-wallpaper` — выбранные обои
- `rumes-folders` — пользовательские папки
