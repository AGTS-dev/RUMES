# Telegram Web Clone - Полная копия Telegram Desktop Web

🎉 **Готово!** Полностью рабочая визуальная копия Telegram Desktop Web с тёмной темой.

## 🚀 Быстрый старт

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск dev-сервера
npm run dev

# 3. Открыть в браузере
# http://localhost:5173
```

## ✅ Что реализовано

### Точная копия визуала Telegram
- ✅ **Цвета 1-в-1**: `#0e1621`, `#17212b`, `#2b5278`, `#182533`, `#3390ec`

- ✅ **Пузыри сообщений** с точными скруглениями и цветами
- ✅ **Hover-эффекты** и анимации 150ms

### Функциональность
- ✅ 12 чатов с русскими именами

## 📱 Адаптивность

### Desktop (>900px)
```
[70px] [360px] [flex: 1]
```
Все три панели видны одновременно.

### Mobile (<900px)
```
[100%] или [100%]
```
Переключение между списком чатов и окном переписки.

## 🎬 Интерактивность

### Отправка сообщений
```javascript
// Enter - отправить
// Shift+Enter - перенос строки
// Кнопка 📤 - отправить
```

### Автоответы
- Задержка: 2-4 секунды
- Индикатор "печатает..." показывается через 500ms
- Случайный ответ из 10 вариантов

### Поиск и фильтры
- Мгновенный поиск по имени чата
- Фильтрация по типу (личные/группы/каналы/боты)
- Автоматический сброс счётчика непрочитанных

## ✨ Анимации

- **Hover**: `transition: all 150ms` на всех элементах
- **Active**: `transform: scale(0.95)` при нажатии
- **Typing dots**: bounce анимация с задержкой 200ms
- **Появление**: плавное появление сообщений

## 🐛 Известные ограничения

- Моковые данные (нет реальной БД)
- Нет WebSocket для real-time
- Нет загрузки файлов
- Нет голосовых/видео звонков
- Нет шифрования
