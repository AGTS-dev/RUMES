### ✅ Исправлены обои в теме "Россия"

#### Проблема
- Обои не применялись в теме "Россия" из-за конфликта CSS правил

#### Решение
- Изменен селектор для фоновых узоров темы "Россия"
- Теперь узоры применяются только если не выбран кастомный wallpaper
- Кастомные обои (Кокошник, Узоры, Берёзовая роща, Русская зима) теперь применяются корректно
- Все обои используют `!important` для приоритета

#### Доступные обои для темы "Россия"
1. **Кокошник** - красно-золотой градиент
2. **Узоры** - традиционные русские узоры
3. **Берёзовая роща** - светло-зеленый градиент
4. **Русская зима** - бело-голубой градиент

## 🚀 Как использовать

### Звонки из вкладки "Звонки"
1. Перейдите на вкладку "Звонки"
2. Найдите нужный контакт в истории
3. Нажмите на иконку телефона справа
4. Откроется модальное окно звонка
5. Дождитесь "подключения" (3 секунды)
6. Завершите звонок красной кнопкой

### Звонки из вкладки "Контакты"
1. Перейдите на вкладку "Контакты"
2. Найдите нужный контакт
3. Нажмите на иконку телефона (аудио) или видеокамеры
4. Откроется модальное окно звонка
5. Управляйте звонком с помощью кнопок

### Обои в теме "Россия"
1. Перейдите в Настройки → Обои
2. Выберите тему "Россия" (если еще не выбрана)
3. Выберите один из 4 тематических обоев:
   - Кокошник
   - Узоры
   - Берёзовая роща
   - Русская зима
4. Обои применятся мгновенно
